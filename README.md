# Hafed Portfolio

الموقع الرسمي الشامل لمعرض أعمال حافظ الشرفي.

## الهيكل
- `index.html`: الواجهة الرئيسية والمعرض.
- `js/projects.js`: قاعدة بيانات المشاريع المعروضة.
- `assets/`: صور المعاينة والشرائح والصفحات المنزوعة من سياق البيانات الشخصية.
- `css/styles.css`: نظام التصميم المتجاوب RTL.

## إضافة مشروع جديد
أضف أصول المشروع داخل `assets/` ثم أضف عنصرًا جديدًا داخل `js/projects.js` مع `categories` و`gallery` أو `liveUrl`.

## الخصوصية
لا تُضاف صفحات تحمل أسماء طلاب أو أرقامًا جامعية أو بيانات اتصال خاصة. تُستخدم صفحات داخلية أو نسخ معاينة آمنة عند الحاجة.

## النشر
الموقع Static ومهيأ لـ GitHub Pages. بعد رفع الملفات، فعّل Pages من إعدادات المستودع واختر النشر من `main` / root أو GitHub Actions.
